링크를 받은 사람이 이름·음료를 정하고 커타에 들어가는 관문 화면.

Notes

커타의 핵심 화면. 큰 커피 주위에 모인 참여자 아바타 위로 채팅 글자가 떠오른다.

  • 트리거: 입장 화면에서 "커타 참여" 후 진입 / 진행 중인 커타에 합류 시
  • 인터랙션: 하단 입력 바에 채팅 입력·전송 → 글자가 장면 위로 떠오름 / 상단 남은 시간·인원 확인 / 아바타는 접속·이탈에 따라 실시간 등장·사라짐
  • 전환: 남은 시간 0 → 종료 화면 / "나가기" → 입장 화면(재입장 가능)

배치 결정: 채팅은 별도 패널이 아니라 커피 장면 위 오버레이(투명 배경, 글자만). 하단엔 입력 바만 고정. 최신 메시지가 아래에 뜨고 오래된 건 옅어지며 사라진다. 모바일·데스크톱 동일 구조(장면 크기만 반응형).
