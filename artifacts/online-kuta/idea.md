# 온라인 커타 (Online 커타) — idea.md

> 상태: 초안 (idea-refine 단계)
> 최종 수정: 2026-07-09

## 한 줄 소개
링크로 연결된 사람들끼리, 온라인에서 잠깐 모여 커피 마시듯 가볍게 수다 떠는 **텍스트 채팅 기반 "온라인 커타(커피 타임)" 앱.**

## 왜 만드는가 (문제)
- 재택·원격근무가 늘면서 "잠깐 나가서 바람 쐬며 수다 떠는" 그 짧은 휴식(담타/커타)을 같이 할 사람이 물리적으로 옆에 없다.
- 화상 통화는 부담스럽고(얼굴·정색), 일반 단톡방은 "쉬는 시간"이라는 맥락이 없다.
- **부담 없이, 짧게, 같이 쉬는** 온라인 공간이 필요하다.

## 누구를 위한 것인가 (대상)
- 서로 **링크(초대)로 연결된 사람들** — 팀원, 친구, 소규모 모임.
- 모르는 사람과의 랜덤 매칭이 아니라, **아는 사람들끼리의 닫힌 방**이 기본.

## 핵심 컨셉
- **방 = 커타 자리.** 초대 링크가 있는 사람만 들어옴.
- **텍스트 채팅이 메인** 소통 수단.
- **짧고 가벼운 휴식**이라는 맥락을 UI가 계속 상기시켜 줌 (타이머, 커피 은유).

## UI 방향
- **픽셀 아트 아바타.** 얼굴을 드러내지 않아 부담이 없고, 아기자기해서 "머물고 싶은" 방이 됨. (게더타운/싸이월드 미니룸 감성)
- 아바타 상태를 그림으로 표현: 커피 든 모습 = 커타 중 / 책상 = 집중 중 / away.

### 화면(스크린) 아이디어
- **① 커타 존 (hero 화면):** 커타를 시작하면 뜨는 메인. **화면 중앙에 큰 커피 컵.** 참여자 아바타들이 화면 밖에서 커피 쪽으로 걸어와, **커피잔 안에 몸을 담그고(목욕/온천처럼) 반신욕하며 늘어져 쉬는** 모습. "-_-" 편안한 표정으로 relax. "지금 같이 쉬는 중"을 한눈에.
  - 재미 디테일: 참여 시 아바타가 걸어 들어와 **커피에 풍덩 들어가는 애니메이션** + "OO 님 참여!" 표시. 커피 표면에 김이 모락모락, 아바타는 "-_-" 표정.
- **② 채팅 화면:** 위쪽은 픽셀 방(아바타들이 커피 테이블에 둘러앉은 모습), 아래쪽은 **텍스트 채팅창.** 실제 수다는 여기서.
- ①과 ②를 위아래로 합칠지 / 탭으로 나눌지는 wireframe 단계에서 배치해보고 결정.

## 기능 아이디어
### 핵심 (MVP 후보)
1. **⏱️ 타이머가 있는 방** — "10분 커타"처럼 시간이 정해져 있고, 끝나면 방이 자동으로 정리됨. 끝나기 30초 전 "곧 커타 끝나요" 알림. → 부담 없음.
2. **🟢 지금 커타 가능 표시** — 연결된 사람 중 "나 지금 쉴 수 있음"을 켠 사람이 초록불로 보임. 약속 없이 "커타 ㄱ?" 찌르기.
3. **🎲 대화 주제 랜덤 뽑기** — 텍스트라 초반이 어색할 수 있으니 "오늘의 커타 질문"을 자동으로 하나 띄워줌 (예: 요즘 제일 아까운 지출은? / 점심 뭐 먹음?).
4. **☕ 커피(음료) 종류 고르기** — 커타 입장 시 아메리카노 / 라떼 / 카푸치노 / 아이스 / 차 등에서 선택. 고른 음료에 따라 **아바타가 든 컵 그림·색이 달라짐.** 개인화 + "오늘 뭐 마셔?" 아이스브레이킹 효과.

### 나중에 (backlog)
5. **빠른 이모지/스티커 반응** — 커피 건네기, 하트, ㅋㅋ 등 타이핑 없이 반응.
6. **📊 커타 기록** — "이번 주 커타 5번", "OO님이랑 제일 많이 커타함" 같은 소소한 통계.
7. **🔕 방해 금지 존중** — "집중 중" 상태면 초대가 아예 안 감.

## 범위 밖 (지금은 안 함)
- 모르는 사람과의 랜덤 매칭 / 오픈 소셜.
- 음성·영상 통화.
- 6번 이후의 backlog 기능들.

## 결정된 것
- **플랫폼: 웹앱** (브라우저에서 바로 열림 → 링크 공유가 쉽고, 실시간 채팅 만들기도 무난). 만드는 사람 = 웹 좀 만들어본 수준.

### 기술 스택 (toy-999 프로젝트 기준)
- **프론트엔드: 이미 세팅된 Next.js 16.2 + React 19 + Tailwind v4 + shadcn** (+ base-ui, phosphor 아이콘, bun). → 이걸 그대로 사용.
  - ⚠️ Next.js 16은 브레이킹 체인지가 있어 구현 전 `node_modules/next/dist/docs/` 문서 확인 필요 (AGENTS.md 규칙).
- **실시간 채팅·접속 상태 = Supabase** 추천. 이유:
  - `Realtime` 기능으로 서버 직접 안 짜도 실시간 채팅이 됨.
  - `Presence` 기능이 "지금 누가 접속 중"을 그대로 지원 → **🟢 커타 가능 표시**에 딱 맞음.
  - DB(Postgres)·로그인까지 한 번에 → 백엔드 부담이 확 줆.
  - (대안: Firebase도 비슷하게 가능. 나중에 비교해도 됨)
- **그래픽 에셋: 이미 만들어진 CC0 픽셀 리소스 사용.**
  - 1순위 **Kenney.nl** (전부 CC0 → 출처 표기·상업적 사용 걱정 없음). 첫 버전 베이스.
  - 보조 **LimeZu "Modern Interiors"** (아늑한 카페 감성. 무료분은 출처 표기 조건 확인 필요).
  - AI 생성 툴(Aether AI 등)은 라이선스·소유권이 애매해 첫 버전에선 제외. 나중에 커스텀 아바타용으로 재검토.

### 배포 구조 (Vercel + Supabase)
- **Vercel** → Next.js 앱(화면) 배포. `git push`로 배포.
- **Supabase** → 실시간 채팅 · 접속 상태(🟢 커타 가능) · 메시지/방 저장(DB) · 로그인. **브라우저가 Supabase에 직접 연결.**
- **핵심 이유:** Vercel은 서버리스라 실시간에 필요한 WebSocket 연결을 오래 유지하지 못함. 그래서 실시간·접속상태는 Vercel에 직접 만들지 않고 **Supabase에 통째로 맡김.** (서버리스 환경에서 실시간 앱 만드는 정석 패턴)

## 아직 결정 못 한 것 (open questions)
