> "무엇을 만들지" 정의: 시나리오 + 성공 기준
> 근거 문서: [idea.md](./idea.md)
> 상태: 초안 (write-spec 단계) · 최종 수정: 2026-07-09

## 1. 개요
링크로 연결된 사람들끼리, 온라인에서 잠깐 모여 커피 마시듯 가볍게 수다 떠는 **텍스트 채팅 기반 커타(커피 타임) 웹앱.** 픽셀 아바타가 큰 커피 주위에 몰려와 함께 쉬는 모습을 보여주고, 정해진 시간이 지나면 커타가 자동으로 끝난다.

**이번 버전(MVP)의 목표:** "링크를 받은 사람이 이름만 넣고 들어와, 음료를 고르고, 다른 사람들과 실시간으로 수다 떨다가, 타이머가 끝나면 자연스럽게 마무리한다" — 이 한 사이클이 매끄럽게 돌아가는 것.

## 2. MVP 범위 (확정)

### 이번에 만든다 (In scope)
- **방 = 초대 링크.** 링크가 있으면 누구나 입장. 방은 상시 존재.
- **이름만 입력하면 입장** (계정/비밀번호 없음).
- **음료 고르기** — 아메리카노 / 라떼 / 카푸치노 / 아이스 / 차. 고른 음료가 내 아바타 컵에 반영.
- **커타 존 화면** — 큰 커피 + 현재 참여자 아바타들이 모여 있는 모습. 누가 들어오고 나가는 게 실시간 반영.
- **실시간 텍스트 채팅** — 같은 방 사람들끼리 메시지를 주고받음.
- **커타 타이머** — 커타 세션에 남은 시간 표시. 끝나기 직전 알림, 시간이 되면 세션 종료.
- **오늘의 커타 질문** — 어색함 방지용 랜덤 대화 주제 1개 표시.
- 인원: **한 방 2~8명** 기준.

### 이번엔 안 한다 (Out of scope → 나중에)
- 아바타가 방을 **걸어다니는** 게더타운식 이동/위치 동기화.
- 계정 로그인, 친구 목록, "연결된 사람에게 커타 찌르기"(방 밖 초대).
- 빠른 이모지/스티커 반응, 커타 통계 기록, 방해 금지 모드.
- 음성·영상, 모바일 네이티브 앱, 커스텀(AI 생성) 아바타.

## 3. 핵심 사용자 시나리오

### 시나리오 A — 커타 시작하고 입장하기
- **상황:** 민지가 팀 커타방 링크를 카톡으로 받았다.
- **흐름:**
  1. 링크를 누르면 입장 화면이 뜬다.
  2. 이름("민지")을 입력하고, 오늘 마실 음료(라떼)를 고른다.
  3. "커타 참여" 버튼을 누른다.
  4. 커타 존 화면으로 들어가고, 내 아바타가 큰 커피 쪽으로 걸어 들어와 자리 잡는다.
- **기대 결과:** 이미 방에 있던 사람들 화면에 "민지 님 참여!"가 뜨고, 민지 아바타(라떼 컵)가 나타난다.

### 시나리오 B — 실시간으로 수다 떨기
- **상황:** 방에 3명이 모여 있다.
- **흐름:**
  1. 화면 아래 채팅창에 "점심 뭐 먹음?"을 입력해 보낸다.
  2. 다른 사람들 화면에 이 메시지가 즉시 나타난다.
  3. 상단에는 "오늘의 커타 질문: 요즘 제일 아까운 지출은?"이 떠 있어 대화 소재가 된다.
- **기대 결과:** 메시지가 1~2초 안에 모두에게 보인다. 누가 보냈는지(이름) 함께 보인다.

### 시나리오 C — 타이머가 끝나 커타 마무리
- **상황:** 10분짜리 커타가 거의 끝나간다.
- **흐름:**
  1. 남은 시간이 00:30이 되면 "곧 커타가 끝나요 ☕" 알림이 뜬다.
  2. 00:00이 되면 커타 세션이 종료되고, 마무리 화면(또는 안내)이 뜬다.
- **기대 결과:** 모두가 동시에 종료를 인지한다. 억지로 붙잡지 않고 자연스럽게 끝난다.

### 시나리오 D — 나가기 / 재입장
- **상황:** 지훈이 먼저 일하러 가야 한다.
- **흐름:**
  1. 나가기를 누르거나 탭을 닫는다.
  2. 남은 사람들 화면에서 지훈 아바타가 사라진다.
  3. 나중에 같은 링크로 다시 들어오면 이름/음료를 다시 고르고 재입장한다.
- **기대 결과:** 접속/이탈이 실시간으로 다른 사람 화면에 반영된다.

## 4. 화면 목록
1. **입장 화면** — 이름 입력 + 음료 선택 + "커타 참여" 버튼.
2. **커타 존 (메인)** — 큰 커피 + 참여자 아바타 + 타이머 + 오늘의 질문.
3. **채팅** — 커타 존 하단(또는 통합 화면)에서 실시간 텍스트 채팅. (배치는 wireframe에서 확정)
4. **커타 종료 안내** — 시간이 끝났을 때 보여줄 마무리 상태.

## 5. 기능 요구사항 (테스트 가능한 형태)
- FR-1: 링크 접속 시 이름 미입력이면 입장 버튼이 비활성 또는 안내가 뜬다.
- FR-2: 음료를 고르면 내 아바타가 든 컵의 그림/색이 선택한 음료로 바뀐다.
- FR-3: 입장하면 같은 방의 다른 참여자 전원 화면에 내 아바타가 2초 이내로 나타난다.
- FR-4: 채팅 메시지를 보내면 같은 방 전원에게 2초 이내로 도착하고, 보낸 사람 이름이 함께 표시된다.
- FR-5: 참여자가 나가면(명시적 나가기 또는 연결 종료) 다른 사람 화면에서 아바타가 사라진다.
- FR-6: 타이머는 모든 참여자에게 동일한 남은 시간을 보여준다(오차 최소).
- FR-7: 남은 시간 30초 전 종료 예고 알림, 0초에 종료 처리가 동작한다.
- FR-8: 오늘의 커타 질문이 방에 하나 표시된다.
- FR-9: 방 인원이 8명이면 그 이상 입장을 막거나 안내한다.
- FR-10: 채팅은 휘발성이다. 보낸 메시지는 커피 주변 임의 위치에서 위로 떠오르다 약 5초 뒤 사라지고 화면에 계속 남지 않는다. 늦게 들어온 사람은 이후 대화만 본다. 저장분은 새 커타 시작 시 정리된다. (사용자 요청, 2026-07-09 — "잠깐 모였다 흩어지는" 커타 컨셉과 일치)

## 6. 데이터 (간단 스케치 — how는 plan에서)
- **room** — 방(=초대 링크). 상시 존재.
- **kuta_session** — 방에서 진행 중인 커타. 시작 시각 / 길이(예: 10분) / 오늘의 질문.
- **participant (presence)** — 지금 방에 접속한 사람. 이름 / 음료 종류 / 아바타 정보.
- **message** — 채팅 메시지. 보낸 사람 이름 / 내용 / 시각.

> 실시간 접속(participant)·메시지는 Supabase Realtime/Presence로, 저장은 Supabase DB로. (상세 설계는 plan.md)

## 7. 성공 기준 (MVP 완료 판정)
이번 버전은 아래가 모두 되면 "완료"로 본다:
- [ ] 링크 하나로 이름만 넣고 입장이 된다.
- [ ] 음료를 고르면 아바타 컵에 반영된다.
- [ ] 두 명 이상이 같은 방에서 서로의 입장/이탈을 실시간으로 본다.
- [ ] 실시간 텍스트 채팅이 오간다(2초 이내 전달).
- [ ] 커타 타이머가 돌고, 끝나면 모두가 종료를 인지한다.
- [ ] 오늘의 커타 질문이 뜬다.
- [ ] Vercel에 배포되어 실제 URL로 접속된다.

**북극성(느낌 기준):** 옆자리 동료 없이도, 링크 하나로 잠깐 모여 커피 한 잔 하듯 수다 떨고 다시 일하러 가는 게 자연스럽다.

## 8. 결정 사항 (MVP)
- **커타 길이:** 10분 고정. (나중에 5/10/15분 선택으로 확장)
- **세션 시작:** 방에 진행 중인 커타가 있으면 합류, 없으면 "커타 시작" 버튼으로 시작.
- **방 개수:** MVP는 링크(방) 하나로 충분. (여러 방은 나중에)
- **이름 중복:** 허용 (제한 없음. 계정 없는 컨셉).
